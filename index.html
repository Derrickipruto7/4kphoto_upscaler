How the pixels get there

  1. 01
    Load the model. Upres loads a pretrained ESRGAN super-resolution network (TensorFlow.js) straight into your browser tab the first time you use it.
  2. 02
    Reconstruct. The neural network upscales your photo 4x, synthesizing plausible edges and texture rather than just stretching pixels.
  3. 03
    Frame it. The result is fit inside a 3840×2160 frame, scaling to the long edge without cropping anything out.
  4. 04
    Done, locally. No file ever leaves your browser tab — there's no server in this pipeline at all. If the AI model can't load, Upres falls back to high-quality resampling automatically.

Upres runs a real machine-learning super-resolution model (ESRGAN, via TensorFlow.js and UpscalerJS) entirely client-side. If the model fails to load — offline, or the CDN is blocked — Upres falls back to browser-native resampling and sharpening so the tool still works.
