How the pixels get there

  1. 01
    Frame it. Upres fits your photo inside a 3840×2160 frame, scaling the long edge up without cropping anything out.
  2. 02
    Resample. The browser's high-quality image smoothing rebuilds every new pixel from its neighbors, rather than just stretching blocks.
  3. 03
    Sharpen. A high-pass layer is blended back over the image to recover edge contrast that resampling softens.
  4. 04
    Done, locally. No file ever leaves your browser tab — there's no server in this pipeline at all.

Upres is a static, client-side tool. Resampling + sharpening only — not a machine-learning super-resolution model. See the README for details and swap-in points if you want to wire up a real ML backend.
